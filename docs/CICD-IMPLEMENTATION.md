# 云效 CI/CD 实现与联调

2026-11-02。对应已确认的 `CICD-INTERACTION-DESIGN.md`。

## 本地实现

- `WorkbenchCore/CICDModels.swift`：连接身份、目录、来源、变量、制品、环境与资源绑定、内存草稿、范围预览、提交回执、远端实例。
- `WorkbenchCore/YunxiaoAPI.swift`：新版 OpenAPI HTTP 传输、完整分页、PAT/Bearer 分离、详情/实例/任务日志、CreatePipelineRun 的 params 字符串编码；Keychain 存取及 OAuth 协议函数。
- `WorkbenchCore/CICDService.swift`：本地事务入口、缓存、关注、映射、运行校验和协调器。提交前保存回执；不重试写请求；未知回执可经人工确认和实例读取后关联。
- `WorkbenchFlowUI`：原生目录、筛选、详情、配置、参数、范围核对、历史与日志。窄窗切为详情内容页，保留返回入口。任务详情可跳到关联实例。
- SQLite v1 → v2 先一致性备份，再升级版本。CI/CD 是可选 payload；不清空任务数据，不改动工作区目录表。旧版应用不识别 schema 2，回退旧包时应从迁移前备份恢复到独立数据目录，保留现库。

## 使用

1. 在真实数据模式的 CI/CD 打开连接设置，选择中心站或 Region。中心站输入组织 ID；Region 输入完整 HTTPS 实例地址。账号标识只用于显示，每次授权建立新的隔离连接身份。
2. PAT 或浏览器授权二选一。确认页面明确列出的站点、组织与读取范围后测试；测试仅完整读取目录，不以触发 Flow 试验运行权限。默认本地只读模式；允许运行需在新连接时关闭只读。
3. 当前会话再次读取真实目录、定义、实例及日志前，明确同意页面所列范围；可能包含生产资源。不会在应用启动时自动查询云效。切换账号/工作区取消旧任务并撤掉本次读取许可。
4. 在概览读取最新定义；关联配置逐个核对代码源与本地已有项目。只使用当前工作区登记的仓库身份，不扫描其他 namespace。
5. 自动支持已知 GetPipeline 代码源结构，无法可靠解析的 YAML/变量/目标需要本地表单补配。必须确认已经核对全部流程及脚本；不支持的分支模式或未识别源会阻止运行。
6. 固定模式列出全部目标；动态模式以真实变量键和值分组，相同值下的所有目标一起显示。纯 CI 需明确证据且不能隐藏部署目标。除精确 dev/test/daily/pre 外全部按生产；流程或资源中出现生产线索也保守阻止。
7. 参数表单逐源选分支或 Tag。覆盖开关关闭意味着保留服务器默认值；开启但输入为空意味着显式提交空字符串。枚举必须选允许值，私密变量用密码框。制品版本为已知值输入，不编造查询候选。
8. 生成预览会重新读取定义；提交前再读取并校验定义、连接、映射和草稿。界面列明环境、资源、动作与影响面。当前生产入口始终拒绝，未假装支持固定提交或不可变制品。
9. 结果未知不自动重试，也不允许同组织、同 Flow 再生成可提交预览；切换账号或重新授权也不能绕过。到云效人工核对唯一实例后，输入真实 ID、确认归属，再读取校验并关联回执。没有唯一可核对结果时保持阻止，不能通过重启解锁。
10. 运行记录完整分页；列表契约缺少状态，最新实例另读，旧实例可按需读取。活跃实例仅查看时轮询，8 秒起步，失败退避到 60 秒；401/403/404 停止。读失败保留云端最后状态。日志按任务加载，仅保留内存，隐藏当前 token 及本次已知私密变量。

## 凭据与数据

PAT、OAuth 访问及刷新令牌只存 Keychain（WhenUnlockedThisDeviceOnly）。不写命令行参数、SQLite、偏好、回执或日志；不读取已有 CLI profile、Cookie 或其他账号凭据。OAuth 草稿、state、verifier、授权码仅在当前授权流程内存使用。HTTP 不携带 Cookie、不缓存响应、不跟随重定向，避免跨域转发凭据。

流水线定义只持久化安全的来源元数据与完整配置摘要，不保存 YAML、webhook、服务凭据字段；运行详情丢弃 globalParams、任务 params/result 等内容。本地回执隐藏变量值、制品值与备注，保留当次目标及配置版本。私密变量不能配置明文默认值。

断开删除本机 Keychain 凭据；历史回执仍隔离保存，不迁移到另一身份。官方未公开撤销端点，因此不宣称远端令牌已失效。当前连接/缓存属于所选工作区；切换到其他工作区需独立建立连接。

## 真实联调边界

离线 fixtures 验证网络契约和状态保护。2026-11-02 的 1.4.2 修复已针对用户指定的中心站组织进行真实 PAT 只读联调：目录共 37 条，分两页返回，终页的 x-next-page 等于当前页码。只有 x-total-pages 独立证明已到末页时才接受该格式，并继续校验 x-total 总条数；未到末页的自引用、回退、矛盾总页数与重复页面仍拒绝，不把部分数据覆盖旧缓存。已在正式应用实际完成“测试连接并保存”，目录显示 37 条，再次通过已保存的 Keychain 凭据刷新成功。没有触发真实 Flow。

尚需真实联调：PAT 的实例读取与运行权限、实例结构差异；OAuth 动态注册接受自定义 URI、浏览器回调、实际 Bearer API 传递、刷新及站点差异；实际流程参数补配与部署范围核对。OAuth 入口明确标注待站点联调，不把 OAuth 当 CLI PAT。

网页关注接口与标准化流水线/实例控制台深链接未核实，因此不宣称同步网页关注或编造自动定位 URL。当前可按流水线 ID 在云效核对，任务日志支持详情返回的 Job ID 或手动已知 ID。批量运行、远端取消/审批/重试与阶段跳过不开放。完整自动解析各 YAML 变体与自动制品/分支候选查询尚未实现；需补配的地方明确展示。

生产开放前还需验证实际不可变版本路径、完整范围及每次生产操作的双重确认；当前所有生产提交均在核心层阻止。
