# 悬浮开发工作台 · V1 开发任务拆分

日期：2026-10-30。依据已确认的《悬浮开发工作台-V1产品规格.md》。

这里的 DEV 编号只用于规划，不是已创建的真实工作台任务、Codex 会话或云效事项。没有执行配置、接入或部署。本表可以在未来工具落地后导入为任务。

## 1. 顺序与里程碑

建议先解决现有 Codex 联动的不确定性，再逐步落地本地界面和适配器；本地交互可在接入验证过程中独立推进。

| 阶段 | 可交付成果 | 通过标准 |
| --- | --- | --- |
| M0 接入验证 | Codex 生命周期验证报告、云效 CLI 契约、原生窗口验证 | 明确哪些能力真实可用、哪些需降级；不靠模型声称成功 |
| M1 本地工作台 | 可记录/勾选任务、项目分支关联、快捷唤出与恢复 | 完全离线仍可用，重启不丢编号和状态 |
| M2 Codex 闭环 | 现有会话按编号关联，记录运行及结果 | 正常/失败/取消/并发/失联均正确，人工状态不变 |
| M3 CI/CD 查询 | 指定项目和环境的真实运行状态 | 与远端实例一致，过期/权限不足有明确提示 |
| M4 指定测试部署 | 预览、确认、触发和结果追踪 | 单项目、提交一致、无重复触发 |
| M5 可安装版本 | 原生提醒、恢复、打包与端到端验证 | 核心闭环及授权规则通过，能力限制明确 |

M0 的 Codex 验证若无法满足现有会话自动同步，须明确报告未通过；可以交付 M1，不得把另开执行通道或主动回写降级方案标成 M2 已完成。生产发布接入是单独后续范围，不是测试部署通过后的自动动作。

## 2. 开发任务

| 编号 | 工作 | 依赖 | 交付物与验收 |
| --- | --- | --- | --- |
| DEV-001 | 现有 Codex 接入能力验证 | 首个明确授权的测试会话/项目 | 验证任务工具调用、会话身份、turn 起止、取消/崩溃/恢复；保留脱敏事件证据并列出缺口 |
| DEV-002 | 云效 CLI 契约验证 | 明确 CLI 路径、版本及指定环境 | 固定查询/触发输入输出映射；检查按提交启动、运行 ID、超时核对能力；初期只读，不触发部署 |
| DEV-003 | 原生悬浮窗口验证 | 最低 macOS/目标机信息 | 置顶、隐藏、焦点、菜单栏、快捷键、全屏/多屏实测；记录平台限制 |
| DEV-004 | 数据模型与单一写入口 | 产品规格 | SQLite 迁移、编号分配、版本检查、事件去重；并发编号唯一、重启可恢复 |
| DEV-005 | 任务列表与圆圈勾选 | DEV-004 | 新建、标题/详情、进行中/已完成、列表详情一致；键盘与失败回滚正确，完成行保留 |
| DEV-006 | 项目、仓库与关联管理 | DEV-004 | 多项目/分支、默认入口、解除与撤销；分支必须属于对应仓库，快照历史保持 |
| DEV-007 | Git 读取与分支关注 | DEV-006 | 只访问登记路径；关注和关联独立；无法读取与删除区分；从分支创建/关联任务 |
| DEV-008 | 悬浮壳、菜单栏与快速记录 | DEV-003、DEV-005 | 快捷唤出、置顶、状态条、Enter 新建、草稿/位置恢复；隐藏服务继续，退出语义明确 |
| DEV-009 | Codex 任务工具与绑定协议 | DEV-001、DEV-004、DEV-006 | resolve/attach、范围校验、默认入口、无效号/歧义处理；只给任务号可正确定位，不切分支 |
| DEV-010 | 执行生命周期适配与汇总 | DEV-001、DEV-009 | 每会话多次运行、并发计数、事件幂等、迟到事件、失联未知；自动事件无权改 is_done |
| DEV-011 | Codex 建议与人工采纳 | DEV-009、DEV-005 | 建议可采纳/忽略，采纳一次只生成一个任务；新任务不自动运行 |
| DEV-012 | 云效状态适配与视图 | DEV-002、DEV-006 | 按项目/环境/实例映射阶段、SHA、时间与结果；离线显示旧数据和同步时间，错误退避 |
| DEV-013 | 部署预览与确认领域逻辑 | DEV-012 | 范围快照、摘要、失效与一次性确认；版本/环境/参数变化失效；生产范围与确认规则强制执行 |
| DEV-014 | 指定开发/测试环境部署 | DEV-013、该次真实部署授权 | 参数安全调用、固定提交、远端 ID 跟踪；双击/超时不重发；实际运行提交与确认一致 |
| DEV-015 | 统一更新、角标与原生提醒 | DEV-008、DEV-010、DEV-012 | 完成仅角标，异常去重提醒；点击正确定位；拒绝通知权限时仍保留站内记录 |
| DEV-016 | 服务生命周期、迁移与恢复 | DEV-004、DEV-008、DEV-010、DEV-012 | 重启/休眠/断网后核对状态；恢复不重发部署；迁移前备份，恢复保留编号、关联与历史 |
| DEV-017 | 打包与端到端验收 | DEV-005–DEV-016 | 可安装构建、能力说明、关键场景报告；最低系统与实际目标架构验证，不默认仅支持 ARM |

可独立推进的工作：M0 三项能力验证彼此分开；数据模型完成后任务界面和项目关联可分开实现。最终集成依赖单一服务契约，不能让各适配器各写一套任务状态。

## 3. 关键验收用例

| 用例 | 操作与预期 |
| --- | --- |
| A01 勾选双向 | 未勾选→已完成→取消→进行中，列表/详情和重启后的结果一致 |
| A02 写入失败 | 勾选保存失败时恢复可信状态并提示，不能界面显示完成而库里未完成 |
| A03 不联动完成 | 任务运行中勾选完成，执行继续；执行/流水线成功不改勾选 |
| A04 并发 | 同任务两个 Run，仅一个结束时仍显示运行中；旧 Run 迟到不覆盖新 Run |
| A05 异常 | 取消、崩溃、断联与等待输入按来源区分；无可靠结束证据时显示未知 |
| A06 绑定范围 | 当前项目优先；无上下文才用默认入口；多分支歧义显式选择；跨命名空间不自动访问 |
| A07 关注与关联 | 取消关注保留任务关联；解除关联保留分支/历史；撤销后关系恢复 |
| A08 编号与采纳 | 并发新建不重号；建议重复采纳不重复建任务；重新打开不分配新号 |
| A09 固定版本 | 预览后分支推进，确认失效；触发/实际运行 SHA 与确认快照一致，否则不得宣称已部署目标版本 |
| A10 重复触发 | 双击确认只提交一次；触发超时不自动重试；重启后先核对远端运行 |
| A11 窗口恢复 | 未置顶点击外部收起、置顶保持；隐藏保留草稿和服务，退出显示同步影响 |
| A12 通知 | 正常完成不抢焦点；重复异常只提醒一次；点击定位正确任务或运行实例 |
| A13 云效故障 | CLI 缺失、认证失效、限流/输出变化显示可理解错误，不误报失败部署或清空历史 |
| A14 权限与确认 | 生产读取先声明范围；生产写入必须与本次明确确认匹配；预览/参数变更后重新确认 |

测试优先覆盖状态竞争、持久化、权限边界和部署重复执行等实质风险。纯样式改动用交互和视觉检查即可，不要求镜像实现的测试。真实部署验收只在用户明确指定的环境和动作范围内进行。

## 4. 接入前所需信息

这些是进入对应开发任务时需要的输入，不阻止当前产品定稿，也不要求现在逐项补齐：

- 代码应创建在哪个明确目录、哪个工作区命名空间。
- 首个用于联动验证的项目/仓库、现有 Codex 会话和允许接入的范围。
- 云效 CLI 的实际路径/命令名、版本、目标项目与流水线映射；凭据留在原安全存储中。
- 测试部署的明确环境、资源、动作与影响面；生产接入另行逐次确认。
- 最低 macOS 版本、需要支持的机器架构；快捷键候选在目标机检查冲突。

## 5. 完成定义

每项任务交付实现、相关验证证据及明确限制。产品完成以真实闭环验收为准，不以原型可点击、工具能启动或模型主动报告完成为准。

推荐最先实施 DEV-001 和 DEV-003，尽早确认现有 Codex 联动与原生悬浮行为；同时以模拟适配器完成 DEV-004/005。没有真实接入授权时仅可推进另行获准的本地实现与模拟验证。
