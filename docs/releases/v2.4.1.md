# Codex Tasks v2.4.1

macOS 原生任务小窗，把待办、Markdown 描述和多个 Codex 会话放在一起。支持 macOS 13+，同一个通用包兼容 Apple Silicon 与 Intel。

## 下载与安装

- **推荐**：下载 `Codex-Tasks-2.4.1-macOS-universal.dmg`，打开后把 Codex Tasks 拖入 Applications。
- **直接解压**：`Codex-Tasks-2.4.1-macOS-universal.zip`。
- **完整性校验**：`SHA256SUMS.txt` 提供两个附件的 SHA-256。

当前包采用 ad-hoc 签名，尚未经过 Apple Developer ID 签名及公证。macOS 首次打开可能提示无法验证开发者；确认来源和校验值后，参照 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 在「系统设置 → 隐私与安全性」查看「仍要打开」。更新前请从菜单栏退出旧版；替换应用会保留本地任务数据。

## 主要功能

- 快速记录任务、手动管理状态，支持一层子任务与进行中筛选。
- 一个任务关联多个 Codex 聊天，显示项目名、运行状态及完成提醒；点击卡片返回聊天。
- 任务描述支持 Markdown 编辑、预览和自动保存。
- 任务卡片与会话卡片任意位置拖动排序，刷新、重启后保留。
- 图钉独立切换置顶，箭头展开／收起详情，默认 `⌘⇧空格` 仅切换显示／隐藏。
- 可选本地 Hooks，及时接收会话状态；任务数据保存在本机。
