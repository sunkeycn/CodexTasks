# 适配器接入契约

目前仅存在进程内协议与模拟实现，没有 HTTP/MCP 监听端口，没有安装插件，没有读取 Codex 配置、会话数据库、Git 仓库或云效认证。不能把协议定义视为外部接入完成。

## Codex

`TaskContextAdapter` 提供 `resolve` 与 `attach`；`ExecutionEventAdapter` 提供 `start`、`report`、`propose`。自动化接口不提供任务人工勾选方法。`MockCodexAdapter` 构造时接受显式 `CallerScope`，只返回和操作授权项目内的元数据。

任务号严格为 `T-正整数`。有当前项目时只在该项目解析：唯一关联分支或项目内默认分支；无项目上下文时使用任务默认入口。歧义、无有效默认、无调用者授权都返回可读错误。当前 Git 分支不一致会返回 `branchMismatch`，不会 checkout。元数据登记不构成磁盘代码访问授权。

会话当前关联可替换，已有执行的任务和范围快照不可迁移。执行事件由全局唯一 eventID、runID、递增 sequence、state 和 summary 构成。同一 eventID 重放幂等；同 ID 不同内容拒绝；旧序号不回退；完成/失败/中断后不允许复活；unknown 允许可靠新事件核对恢复。并发运行计数按全部 Run 汇总。重复异常按 Run 和状态去重，正常完成只产生站内记录与角标。

真实接入前仍需：明确指定现有测试会话与项目；证明开始、完成、取消、崩溃、断联、多 turn、并发和重连事件的来源与顺序；校验调用者身份和目录 realpath/namespace 范围。主动工具回写无法证明进程崩溃或强制退出，应标记降级来源，不能宣称可靠自动同步完成。另开执行通道不替代现有会话需求。

## 云效

`PipelineAdapter` 提供 listRuns / prepare / confirm。当前 `MockPipelineAdapter` 只读写本机数据库，远端实例 ID 为 mock- 前缀，SHA 为模拟值；实际部署能力始终为 false。

预览保存项目、分支、环境、资源、动作、影响面、完整 SHA、流水线、参数、关联任务及摘要。单项目生成新预览使该项目旧未提交预览失效；分支推进使该分支旧未提交预览失效；界面修改环境、分支、任务或参数会丢弃当前预览。确认必须携带原摘要，服务复核分支 SHA、可用性和关联，15 分钟超时需重做。第一次确认在事务中生成并绑定唯一实例，后续确认只返回原实例，包括未知结果和重启后。不存在自动重试路径。

真实 CLI 接入前需要：明确可执行文件与版本、查询/触发命令、脱敏输出、实例映射、固定提交能力、请求关联 ID/去重或超时核对策略。应使用 Process.executableURL + arguments，不能拼接 shell；任务文字和参数不可执行。凭据留在既有安全存储中，不放入数据库或日志。失去认证、限流、CLI 缺失、输出变化时保留旧结果与最后同步时间，使用错误退避，不能冒充失败部署或已成功上线。

dev/test/daily/pre 之外均按生产处理。本版拒绝所有其他环境的预览，未实现真实生产读取或写入入口。后续生产读取先声明；生产写入须先列环境、资源、动作、影响面，再获得该次具体范围的明确确认，不能沿用设计授权。
