# Codex Tasks 1.2.0

日期：2026-11-02。本次为本地应用更新，未操作生产资源或修改 Codex 数据。

## 使用

从菜单栏退出仍在运行的旧版，然后打开 `outputs/Codex Tasks.app`；发布包为 `Codex-Tasks-macOS.zip`，源码包为 `Codex-Tasks-源码.zip`。

- 应用名称统一为 Codex Tasks。
- 任务名右侧「提示词」复制 `关联Codex Task【T#01】`。将它独立成行发送到目标 Codex 会话即可首次关联；也可在详情手动选会话。旧关联指令兼容。
- 关联后的任务名下显示浅灰色 `| 会话名称`，点击通过系统 URL 打开对应 Codex 会话。
- 左侧工作区菜单切换 sunkey / ShopLnkit。应用设置（⌘,）手动新增、编辑和移除目录绑定。每次使用一个工作区；任务、项目、草稿、执行历史各自隔离，记住上次选择。
- 移除工作区保留本地数据，重新添加同一目录可恢复。已有数据的工作区可改名，绑定新目录请新增。任务编号在各工作区独立分配。

本应用直接只读 Codex 的本机索引和日志；关联指令仅决定首次对应关系，之后每 5 秒同步。因此没有增加应用设置中的关联协议提示词，也没有实现向 Codex 自动发送消息。

## 数据兼容

原 sunkey 数据保留在 `~/Library/Application Support/FloatingWorkbench/Live/workbench.sqlite`。工作区目录表和上次选择保存在同目录 `workspaces.json`，其他工作区数据库在 `workspaces/<UUID>/workbench.sqlite`。保留原 bundle identifier 和内部可执行名以兼容已有数据与系统偏好。

本次预置 ShopLnkit 目录绑定，未遍历其中源码。各工作区只读自己的会话和已关联目录 Git 元数据。备份导出仅包含当前工作区；全量备份还需目录表和其它工作区的一致性数据库副本。
