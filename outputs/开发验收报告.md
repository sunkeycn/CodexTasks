## 自动化验收

`./scripts/test.sh` 运行独立 Swift 验收程序：25 项全部通过。重点覆盖编号持久化与并发、失败回滚、乐观版本冲突、勾选幂等、人工/自动状态隔离、迟到/重复事件、重启与未知恢复、关注/关联独立、默认入口/授权/歧义、会话换绑历史、建议采纳并发、固定 SHA、新范围失效、重复确认、生产环境拒绝、备份恢复和旧结构保护。

本机 Command Line Tools 不带 XCTest，所以使用无外部依赖的可执行验收程序；每项断言失败会返回非零退出码，JSON 保存逐项结果。没有把缺少测试环境记作通过。

`./scripts/test-window.sh` 启动真实打包 app，使用独立数据目录：14 项全部通过。包括实际 AppKit 窗口和 SwiftUI 承载、菜单栏、快捷键注册、关闭隐藏、注入失焦下置顶/非置顶、收条/展开、草稿/服务保留，以及通过 AppModel 新建/完成/恢复。截图为 app 自身内容视图实际渲染。

外部 UI 自动化获取菜单栏应用窗口返回 `cgWindowNotFound`，因此未计入鼠标点击或物理快捷键测试。无论代码与自测是否通过，实际多屏、全屏空间、睡眠唤醒与原生通知行为均仍需在目标机验证。

## 实现取舍与剩余工作

- SQLite 当前采用一个序列化状态文档，在数据库事务中完整读改写，避免多个界面或适配器维护独立状态；适用于个人首版。事件历史量大时应迁移为分表索引，当前没有全量历史导入或自动清理。
- 真正的后台服务仍与 app 同进程；隐藏不停止，退出会停止。当前没有独立常驻 daemon 或开机启动项。
- 注册的路径仅为元数据；真实访问必须额外校验调用者身份、真实路径、命名空间、项目授权和环境范围。不得将目前的进程内协议直接无鉴权暴露到网络。
- 真实云效部署必须证明可以锁定实际提交；仅检查一次可变分支头不够。真实触发超时必须核对远端实例，不能复制模拟实现后直接重试。
- 当前没有签发或读取任何凭据，也没有真实生产/测试资源操作。真实接入缺口不影响本地任务与模拟验收的使用。
