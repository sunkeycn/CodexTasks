# 悬浮开发工作台 · 本地 V1

交付日期：2026-10-30（Asia/Shanghai）

当前交付一个可运行的 macOS 原生应用，完成本地任务管理、项目/分支元数据关联和模拟执行闭环。真实 Codex 与云效尚未接入。

## 打开应用

直接打开同目录 `悬浮开发工作台.app`。也提供 `悬浮开发工作台-V1-macOS.zip`，解压后可放入自己的 Applications 目录。

- ⌘⇧空格：唤出或隐藏。如果组合键被占用，应用会提示，可使用菜单栏入口。
- ⌘N：聚焦快速记录；输入后按 Enter 新建。
- 任务前圆圈：完成 / 恢复进行中。选中任务且不在文本框时，可按空格。
- 顶部图钉：置顶；未置顶时切换到其他应用会隐藏。
- 顶部收条按钮：收成显示运行数与更新数的状态条，点击展开。
- 关闭窗口 / Esc：隐藏，服务与快速记录草稿保留。
- 真正退出：从菜单栏选择“退出工作台…”，会说明同步停止的影响。

首次启动仅创建一个明确标注的示例项目和任务；登记项目不会读取本机代码。完成任务不会终止执行，执行或流水线成功也不会勾选任务。

## 数据与备份

默认数据库目录：`~/Library/Application Support/FloatingWorkbench/`。本次开发验收使用项目的 `work/` 隔离目录，不把验收数据带入默认用户数据库。

详情修改需点“保存详情”。快速记录草稿实时保存；普通隐藏和收成状态条保留当前编辑视图。真正退出前应保存详情。

菜单栏可导出完整数据库备份。恢复时先退出应用，把备份放入**新的空目录**并改名 `workbench.sqlite`，然后通过源码中的启动脚本指定该目录。保留旧目录用于回滚；不要将备份覆盖到仍有旧 WAL 的目录。

```sh
cd /Users/sunkey/WorkSpace/sunkey/floating-dev-workbench-v1
./scripts/run.sh --data-directory /绝对路径/新的恢复目录
```

## 构建与复验

源码位于当前任务目录，并附同目录 `悬浮开发工作台-V1源码.zip`。解压源码后：

```sh
./scripts/test.sh
UNIVERSAL=1 ./scripts/build-app.sh
./scripts/test-window.sh
./scripts/run.sh
```

没有第三方依赖，使用 Swift、AppKit、SwiftUI 和系统 SQLite。仅 Command Line Tools 即可构建；验收程序不依赖 XCTest。

应用包包含 Intel x86_64 与 Apple Silicon arm64。编译最低目标 macOS 13；实际运行验证为本机 macOS 26.6.2 / Intel。Apple Silicon 实机与 macOS 13 实机尚未验证。采用本地 ad-hoc 签名，未做 Developer ID 签名或 Apple 公证。
