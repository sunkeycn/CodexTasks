# 真实 Codex 接入版 · V1.1

默认启动本机真实数据模式。双击 `悬浮开发工作台.app`，在底部记录任务，得到 `T#01`，将自动复制的 `关联任务【T#01】` 放在 Codex 提示词最后独立一行发送。工作台每 5 秒同步；任务详情可立即同步、查看会话名/ID/目录、手动关联已有会话。

任务与会话严格一对一，项目和分支随会话记录追加，项目列表显示关联任务总数。任务是否完成仍由人工勾选。

默认接入范围为 `~/WorkSpace/sunkey`。工作目录跟随的是工作台里的项目记录；不修改 Codex 全局项目或会话目录。仅支持结构化 cwd/workdir 的项目发现。等待审批/输入/失败状态尚未有完整可靠映射，日志超过 3 分钟没有更新会显示同步未知。CI/CD 未接入。

真实数据默认位于 `~/Library/Application Support/FloatingWorkbench/Live/`，旧模拟库保留。应用为 Intel + Apple Silicon 通用包，ad-hoc 签名。完整操作与 CLI 调试说明见 `docs/REAL-CODEX.md`。
